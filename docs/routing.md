# Rutas y navegación

La aplicación usa React Router.

## Rutas

- `/`: página de inicio.
- `/login`: login simulado.
- `/doctors`: listado de doctores.
- `/appointments`: gestión de citas.
- `/consultations`: historial de consultas.
- `*`: página 404.

## Navegación

La navegación se realiza desde el componente `Navbar` usando `NavLink` y `Link`.
