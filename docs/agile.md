# Investigación: metodologías de desarrollo

## Agile

Agile es una forma de trabajar en proyectos de software que busca entregar valor poco a poco, en lugar de esperar hasta el final para enseñar todo el producto. Su objetivo es adaptarse mejor a los cambios, recibir feedback rápido y mejorar el producto durante el desarrollo.

En un proyecto como MediClinic App, Agile permite construir primero una versión básica con doctores y citas, probarla, corregir errores y después añadir consultas, login o mejoras visuales.

## Scrum

Scrum es una metodología ágil organizada en ciclos cortos llamados sprints. Un sprint suele durar una o dos semanas. Durante ese tiempo, el equipo elige tareas del backlog y trabaja para entregar una parte funcional del producto.

Conceptos principales:

- Product Owner: persona que define prioridades y necesidades del producto.
- Scrum Master: persona que ayuda a que el proceso Scrum se cumpla.
- Equipo de desarrollo: personas que construyen el producto.
- Sprint: periodo corto de trabajo.
- Backlog: lista de tareas o funcionalidades pendientes.
- Sprint Review: revisión del trabajo terminado.
- Retrospective: reflexión sobre qué salió bien y qué se puede mejorar.

## Kanban

Kanban es una forma visual de organizar tareas usando columnas. Las tareas se mueven según su estado. Por ejemplo: Backlog, Todo, In Progress, Review y Done.

En este proyecto uso Kanban con Trello porque me permite ver claramente qué tareas faltan, cuáles estoy haciendo y cuáles ya terminé.

## Diferencias entre Scrum y Kanban

Scrum trabaja con sprints definidos y roles concretos. Kanban es más flexible y se centra en visualizar el flujo de trabajo. Scrum suele tener más estructura. Kanban es más simple para proyectos individuales o trabajos donde las prioridades cambian mucho.

## Cuándo usar cada metodología

Scrum se puede usar cuando hay un equipo, un producto grande y se quiere trabajar por entregas periódicas. Kanban se puede usar cuando se quiere organizar el trabajo de forma visual y flexible. Para este proyecto individual, Kanban es más sencillo porque puedo mover tarjetas según avance.
