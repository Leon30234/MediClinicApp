# Organización del proyecto

Para organizar el trabajo se utiliza un tablero Kanban en Trello.

## Columnas del tablero

- Backlog: ideas y tareas generales pendientes.
- Todo: tareas que se harán próximamente.
- In Progress: tareas que están en desarrollo.
- Review: tareas terminadas que necesitan revisión.
- Done: tareas completadas.

## Tarjetas principales

- Crear proyecto Vite con React y TypeScript.
- Configurar Tailwind CSS.
- Configurar React Router.
- Crear estructura de carpetas.
- Crear backend con Express.
- Crear rutas REST.
- Crear cliente de API tipado.
- Crear páginas principales.
- Crear formularios controlados.
- Crear documentación.
- Probar aplicación.
- Desplegar en Vercel.

## Subtareas técnicas

Cada tarjeta se divide en subtareas pequeñas para poder avanzar de forma ordenada. Por ejemplo, la tarjeta de citas incluye crear endpoint GET, crear endpoint POST, crear formulario, validar campos y mostrar mensajes.
