# Reflexión final

Durante este proyecto aprendí a conectar un frontend de React con TypeScript con un backend creado con Express. También aprendí la importancia de separar responsabilidades: los componentes muestran información, los hooks gestionan lógica de React, el cliente de API centraliza las llamadas y el backend organiza rutas, controladores y servicios.

Uno de los principales problemas fue entender cómo conectar el frontend con la API y cómo mantener los tipos alineados entre ambas partes. Para resolverlo, definí interfaces claras como `Doctor`, `Appointment` y `Consultation`.

También aprendí a documentar el proceso completo en la carpeta `docs/`, no solo el código final. Esto ayuda a explicar cómo se ha organizado el proyecto y qué decisiones se tomaron.

## Uso de IA

Utilicé IA como apoyo para organizar la estructura del proyecto, entender el enunciado, plantear la arquitectura y redactar documentación inicial. Después revisé el resultado para adaptarlo a mi proyecto y entender cada parte del código.
