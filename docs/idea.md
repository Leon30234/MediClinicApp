# Idea del proyecto

## Nombre

MediClinic App

## Descripción

MediClinic App es una aplicación web para una clínica pequeña. Permite gestionar doctores, citas médicas y consultas desde una interfaz sencilla.

## Problema que intenta resolver

Muchas clínicas pequeñas pueden tener problemas para organizar sus citas, consultar la disponibilidad de doctores o mantener un historial básico de consultas. Esta aplicación intenta centralizar esa información en una web fácil de usar.

## Usuario objetivo

Los usuarios principales serían pacientes, personal administrativo y médicos de una clínica.

## Funcionalidades principales

- Login simulado de usuario.
- Ver listado de doctores.
- Crear cita médica.
- Ver citas programadas.
- Cancelar citas.
- Ver consultas médicas de ejemplo.
- Navegar entre páginas con React Router.

## Funcionalidades opcionales

- Registro real de usuarios.
- Roles separados para paciente, médico y administrador.
- Buscador de doctores.
- Filtro por especialidad.
- Confirmación por correo.
- Calendario visual.

## Mejoras futuras

En el futuro se podría añadir base de datos real, autenticación con JWT, panel de administración completo y despliegue independiente del backend.
